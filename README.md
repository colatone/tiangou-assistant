# 时光计算器 - 时间跨度记录小程序

一款温馨简洁的微信小程序，用于记录和展示生命中的重要时刻。

## 功能特性

### 核心功能
- **正计时模式**：记录并展示已过去的天数（出生天数、恋爱天数、纪念日等）
- **倒计时模式**：记录距离未来某天的剩余天数，支持实时秒级刷新（天/时/分/秒）
- **卡片式首页**：以卡片列表展示所有事件，支持按分类筛选和多种排序

### 🆕 农历日历功能
- **双历法对照展示**：选择日期后自动显示对应的农历日期（农历月/日）
- **二十四节气**：精确计算并标注当前日期所属节气
- **节假日标注**：包含公历节日（元旦、国庆、情人节等）和农历节日（春节、中秋、端午、七夕、除夕等）
- **天干地支与生肖**：显示农历年的干支纪年和生肖信息
- **高亮标签**：重要节日/节气以彩色标签突出显示
- **首页卡片农历**：每个事件卡片的日期区域展示对应农历日期和节日/节气标注

### 🆕 分享卡片集成小程序码
- **Canvas 绘制精美分享卡片**：渐变背景 + 圆角内容区 + 装饰元素
- **嵌入小程序码图片**：卡片右下角清晰展示小程序二维码
- **农历信息展示**：卡片中同时展示公历日期和农历对照
- **保存到相册** / **分享给好友** / **分享朋友圈**

### 🆕 倒计时通知提醒
- **自定义提醒时间节点**：可设置提前 1/3/7/15/30 天提醒
- **开关控制**：可随时开启或关闭提醒
- **本地通知推送**：
  - 小程序启动时自动检查待处理提醒
  - 切回前台时再次检查
  - 通过 Modal 弹窗形式展示提醒消息
- **界面实时展示**：
  - 倒计时事件在首页以「天:时:分:秒」格式实时刷新
  - 当剩余天数 < 30 天时自动显示时分秒
  - 当剩余 < 1 天时显示秒级倒计时
  - 已到达目标日显示庆祝标记 🎉
- **智能清理**：过期且已通知的提醒自动归档清理

### 事件管理
- **添加/编辑/删除**：完整的事件 CRUD 操作
- **自定义分类**：预设 7 种分类（生日🎂、恋爱❤️、节日🎉、纪念日🌟、旅行✈️、工作💼、自定义🏷️），支持用户创建新分类

### 每日语录
- 首页顶部每日一句温馨语录，50+ 条语录库，每日自动更换

## 页面结构

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `pages/index/index` | 卡片列表、每日语录、筛选排序、实时倒计时 |
| 添加/编辑 | `pages/add-event/add-event` | 事件表单（含农历展示、提醒设置） |
| 分类管理 | `pages/category/category` | 查看/添加/删除自定义分类 |
| 分享卡片 | `pages/share-card/share-card` | Canvas 精美分享图（含小程序码） |

## 设计风格

- **浅色温馨风格**：暖白背景 `#FFF8F0`，珊瑚橙主色调 `#FF8C69`
- 柔和圆角卡片、渐变文字、浮动添加按钮
- 正计时卡片左侧橙色渐变条，倒计时卡片左侧蓝色渐变条
- 农历信息区采用暖色调背景（米色→粉色渐变），左侧橙色边框强调
- 节气/节日标签按类型使用不同配色（蓝=节气、红=大节、橙=公历节、紫=传统）

## 技术栈

- 微信小程序原生框架（MINA）
- `wx.getStorageSync` / `wx.setStorageSync` 本地数据持久化
- `canvas 2d` API 绘制分享卡片（含二维码图片嵌入）
- 自实现农历转换算法（1900-2100 年），无外部依赖

## 使用说明

1. 使用微信开发者工具打开本项目目录
2. 点击"编译"即可预览
3. 首次启动会自动初始化示例数据（出生日期、恋爱纪念日、新年倒计时）

## 农历模块说明 (`utils/lunar.js`)

- 支持年份范围：1900 - 2100
- 包含完整的农历月大小表（含闰月处理）
- 内置 24 节气近似计算
- 公历节日 16 个 + 农历节日 11 个
- 天干地支、生肖映射
- API：`solarToLunar()`, `formatLunarInfo()`, `getFullLunarInfo()`, `getSolarTerm()`
